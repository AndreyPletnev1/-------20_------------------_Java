# Лабораторная работа № 2 — вариант 20

## Запуск

Откройте папку проекта в VS Code и запустите `Main.java` кнопкой **Run Java**. При старте появится меню:

```text
1 — Шифрование
2 — Расшифрование
0 — Выход
```

Либо соберите и запустите из терминала в папке проекта:

```powershell
javac -encoding UTF-8 -d out Main.java
java -cp out Main
```

При выборе шифрования программа читает исходный текст и начальную позицию, создаёт случайный ключ, а затем сохраняет шифртекст, ключ и отчёт. При выборе расшифрования программа отдельно читает уже сохранённые `ciphertext.txt` и `key.txt`; новый ключ не создаётся. После каждой операции подробная таблица символов и алфавиты всегда выводятся в консоль. Полный отчёт также записывается в `data/report.txt`. Папка `data` ищется как в текущей папке запуска, так и рядом со скомпилированным проектом.

## Файлы

- `data/input.txt` — исходный английский текст для шифрования. Текст автоматически переводится в верхний регистр.
- `data/start_position.txt` — начальная позиция в последовательности ключа, нумерация с нуля. Пример: `0`.
- `data/key.txt` — сохранённая начальная позиция и случайная последовательность цифр; формат создаётся программой.
- `data/ciphertext.txt` — результат шифрования.
- `data/decrypted.txt` — результат отдельной операции расшифрования.
- `data/report.txt` — использованные алфавиты без рамок и таблица промежуточных значений.
- `out/` — скомпилированные Java-файлы.

Для расшифрования нужны непустые `data/ciphertext.txt` и `data/key.txt`. Длина ключа должна покрывать начальную позицию и все символы шифртекста. При отсутствии или ошибочном содержимом файлов программа сообщает, какой файл или данные нужно исправить.

## Алфавит и алгоритм

Алфавит содержит 30 символов в неизменном порядке: `ABCDEFGHIJKLMNOPQRSTUVWXYZ .,?` (латинские буквы, пробел, точка, запятая и вопросительный знак). В отчёте он показан как 5 строк по 6 символов с пробелами между ячейками; `[ ]` явно обозначает пробел. Рамки таблицы не используются.

Для каждой позиции используется соответствующая цифра ключа:

- шифрование: `C_i = (M_i + K_i) mod 30`;
- расшифрование: `M_i = (C_i - K_i + 30) mod 30`.

Начальная позиция указывает, с какой цифры сохранённой последовательности начинается обработка. Таблица в отчёте показывает порядковый номер, символ исходного текста, его код, цифру ключа и код/символ шифртекста.
